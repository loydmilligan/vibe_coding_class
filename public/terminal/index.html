Terminal Basecamp

From a Windows PC to Linux, Codex, Docker and your own AI helper, one command at a time.

How this works

  • Each lesson teaches one command: what it does, the command to copy, then a small exercise.
  • Each section ends with a bigger task that uses everything in it. Finishing it unlocks the next section.
  • Stuck? Press Ask the helper on any exercise. It starts with small hints, and if you keep asking, it walks you through the whole thing. That's how it's meant to be used: no shame in step 4.
  • Copy with the icon; paste into a terminal with right-click.
