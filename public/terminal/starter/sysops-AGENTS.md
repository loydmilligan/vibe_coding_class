# sysops-agent

This project looks after my computer: a Ubuntu system running in WSL2 on Windows.

## About me
- My name is Sarah. I'm new to the terminal and learning as I go.
- Explain every command in plain words before you run it, and what its output means after.

## The machine
- Windows PC with WSL2 and Ubuntu. My projects live in ~/projects.
- My Windows files are under /mnt/c/Users/.

## Rules
- Ask before running any command that changes something. Reading is fine.
- Never run sudo. If something needs admin rights, tell me the exact command and I'll run it myself.
- Never delete anything outside this folder. Inside it, ask first.
- Never read, print or copy any .env file, password or key.
- Don't use git commit or push. I'm learning git separately.
- Keep notes of what we did in notes/log.md: date, what I asked, what changed.
